# HDL Fundamentals

A collection of Verilog/SystemVerilog projects covering the fundamentals of Hardware Description Language (HDL), including behavioral, structural, gate-level, and switch-level modeling.

## Topics Covered
- Behavioral Modeling
- Structural Modeling
- Gate-Level Modeling
- Switch-Level Modeling

## Language
- Verilog
- SystemVerilog
